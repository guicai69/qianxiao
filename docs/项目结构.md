# 项目目录结构说明

> 本项目是 **Django + DRF 后端 + Vue 3 + Element Plus 前端** 的全栈系统。
> 顶层组织参照标准 Python 项目结构（README / 依赖清单 / .gitignore / 源码包 / 测试 / 文档），
> 具体目录按 **Django 官方约定**（apps + config 分层）与 **Vue 官方约定**（src/views/components 分层）落位。

## 一、顶层结构

```
羽毛球馆管理系统/                 # 项目根
├── README.md                    # 项目说明：功能、运行方式、测试账号
├── .gitignore                   # 指定不提交 Git 的文件（依赖/缓存/本地目录）
├── docker-compose.yml           # 容器编排（后端 + 前端 + MySQL + Redis）
├── start.bat                    # 一键启动（自动检测并安装依赖后启动前后端）
├── stop.bat                     # 一键停止（按端口结束前后端进程）
├── AGENTS.md                    # 开发约定（技术栈/命令/代码规范）
├── backend/                     # 后端源码包（Django）
├── frontend/                    # 前端源码包（Vue 3）
├── docs/                        # 项目文档
└── deploy/                      # 部署配置（nginx 反向代理）
```

> 本地开发时还会出现 `.venv/`、`frontend/node_modules/`、`logs/`、`.idea/` 等生成物，均已在 `.gitignore` 中排除，不属于项目代码。

## 二、后端 `backend/`

```
backend/
├── manage.py                    # 入口程序：runserver / migrate / test
├── requirements.txt             # 依赖清单（第三方库）
├── badminton_venue.sql          # 数据库结构 + 演示数据导出
├── gunicorn.conf.py             # 生产 WSGI 配置
├── Dockerfile                   # 后端镜像
├── README.md                    # 后端说明
├── config/                      # 项目配置模块
│   ├── settings/
│   │   ├── base.py              # 公共配置（DB / JWT / CORS / DRF / 日志 / 缓存）
│   │   ├── dev.py               # 开发覆写
│   │   └── prod.py              # 生产配置
│   ├── urls.py                  # 根路由 + Swagger（/api/docs/）
│   ├── api_urls.py              # 各 app 路由聚合
│   ├── celery.py                # Celery 配置（定时取消过期订单）
│   ├── asgi.py / wsgi.py        # 服务器入口
│   └── __init__.py              # 导出 celery app
├── apps/                        # 业务模块（按领域拆分）
│   ├── users/                   # 用户认证（登录/JWT/角色/会员等级/积分）
│   ├── venues/                  # 场馆 / 场地 / 时段
│   ├── bookings/                # 预约订单 + 冲突检测 + 取消政策
│   ├── payments/                # 支付 / 充值 / 退款
│   ├── coupons/                 # 优惠券 + 积分兑换
│   ├── activities/              # 活动/比赛/培训/教练课 + 报名核销
│   ├── reviews/                 # 评价 / 收藏 / 意见反馈
│   ├── stats/                   # 数据统计（无模型，纯接口）
│   ├── announcements/           # 系统公告
│   └── common/                  # 公共工具（缓存封装 / 图形验证码）
└── logs/                        # 运行日志（启动时自动创建，不提交）
```

每个业务 app 内部统一采用 Django 标准分层：

```
apps/<app>/
├── __init__.py
├── apps.py                      # AppConfig（verbose_name 中文）
├── models.py                    # 数据模型（choices 常量定义在顶部）
├── serializers.py               # List / Detail / Create 序列化器
├── views.py                     # ViewSet + 权限 + 自定义动作
├── urls.py                      # DefaultRouter 注册
├── tests.py                     # 接口测试
├── tasks.py                     # 定时任务（按需，如 bookings）
└── migrations/                  # 数据库迁移
```

## 三、前端 `frontend/`

```
frontend/
├── package.json                 # 依赖清单 + npm 脚本
├── vite.config.js               # 构建配置（@ 别名 → src/，/api 代理 → 8000）
├── vitest.config.js             # 单元测试配置
├── index.html                   # 入口 HTML
├── Dockerfile / nginx.conf      # 部署用
├── public/                      # 静态资源
└── src/
    ├── main.js                  # 入口：注册 ElementPlus/Pinia/Router
    ├── App.vue                  # 根组件
    ├── style.css                # 全局样式入口
    ├── api/                     # axios 封装 + 各模块 API
    ├── router/                  # 路由（/admin /reception / /login）
    ├── store/                   # Pinia 状态（token / userInfo）
    ├── utils/                   # 工具（请求拦截 / 格式化 / 下载 / 充值）
    ├── styles/                  # 设计令牌 tokens.css + 基础样式
    ├── components/brand/        # 品牌组件（AuthShell / CourtScene）
    ├── layouts/                 # 布局（AdminLayout / MemberLayout）
    └── views/                   # 页面
        ├── Login.vue / Register.vue / NotFound.vue
        ├── admin/               # 管理端：看板/场馆/场地/时段/预约/支付/公告/活动/优惠券/用户
        ├── reception/           # 前台：操作台
        └── member/              # 会员端：首页/场馆/订单/支付/活动/优惠券/个人中心
```

## 六、与图中的标准结构对照

| 图中结构 | 本项目对应 | 说明 |
|----------|-----------|------|
| `README.md` | `README.md` | 项目说明 |
| `requirements.txt` | `backend/requirements.txt` | 依赖清单（Django 约定放在后端目录） |
| `.gitignore` | `.gitignore` | 忽略依赖/缓存/本地目录 |
| `src/` | `backend/` + `frontend/` | 前后端分离，各占一个源码包 |
| `src/main.py`（入口） | `backend/manage.py` | 入口程序 |
| `src/core/`（业务逻辑） | `backend/apps/` | 核心业务模块（按领域拆 10 个 app） |
| `src/config/`（配置） | `backend/config/settings/` | 配置模块 |
| `src/utils/`（工具） | `backend/apps/common/` + `frontend/src/utils/` | 通用工具 |
| `src/data/`（数据存储） | `backend/apps/*/migrations/` + MySQL | 数据由关系库 + 迁移管理 |
| `tests/`（测试） | `backend/apps/*/tests.py` + `frontend/src/**/__tests__/` | Django/Vue 约定就近存放 |
