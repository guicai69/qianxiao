## 2. 隐喻

**蓝图 + 接触印相表**。
球场本来就是一块带线框的矩形，一排球场就是一张印相表，编号、格线、逐格挑选，正好就是"选场地"这个动作本身。整站底纹是一张**蓝图格纸**，球场按真实尺寸画成图纸。
所以 `01–05` 的编号是**有理由的**（天河 01 … 越秀 05，跟着区走），不是装饰。

## 3. 颜色（唯一真源：`src/styles/tokens.css`）

**蓝白**。两个平面：

| 角色 | light（全站默认） | deep（夜蓝重音） |
|---|---|---|
| 页面底 | `#eef2f8` | `#0b1220` |
| 面板 | `#fcfdff` | `#121c30` |
| 正文墨色 | `#101b2e` / `#3b4a63` / `#5b6a83` / `#64728a` | `#e9eefb` / `#b3bfd6` / `#8b98b3` / `#7d8aa5` |
| 主色 | `#1a5fd0` | `#5b9dff` |
| 副色（青） | `#0e6b86` | `#4fd1e8` |
| 语义 | 成功 `#157f52` · 危险 `#c8392f` · 警示 `#b26a08` · 信息 `#0f8ba8` | 成功 `#3fcb86` · 危险 `#ff6156` · 警示 `#e8a33d` · 信息 `#5cc0e0` |
| 侧栏 rail | — | `#0d1526` |

`deep` 只用在四块地方：**后台侧栏、登录页左侧、首页收尾条、404**。它是"换幕"，不是默认。

规则：
- **不用纯白 `#fff`、不用纯黑 `#000`**。所有中性色朝主色温度偏 2 个点（所以页面底是带蓝的纸，不是灰白）。
- **主色锁死**：蓝只做一件事（主操作 / 可点状态 / 图表第一色）。棋盘上 70 个价格用墨色，蓝色只留给悬停与聚焦 —— 重复 70 次的强调色等于没有强调色。
- 亮底上的主蓝 `#1a5fd0` 保证白字 5.7:1；`--ink-3/4` 分别 5.4:1 / 4.8:1，都过 AA。
- Element Plus 的浅色变体全部用 `color-mix(in srgb, var(--某色) N%, var(--surface))` 现算，**不要手写 hex**：切平面时底色一变，变体自动跟着变。

## 4. 字体与数字

- **不加载任何网络字体**（答辩现场断网也不掉字）。中文用系统栈：`PingFang SC / Microsoft YaHei / Noto Sans SC`。
- **数字（金额、时间、编号、手机号）一律 monospace + `tabular-nums`**，加 `class="mono"`。
- 标题 800/900 配负字距（`-0.02 ~ -0.035em`），正文 300/400。

## 5. 动效（第二轮已加强）

**预算**：重头戏（要引擎的）**1 个**；总拍数 5 拍封顶；同一家族每拍只出现一次；跑马灯 0 条。

| # | 位置 | 家族 | 做了什么 | 理由 |
|---|---|---|---|---|
| 1 | 首屏 | 空间 + 几何 | 蓝图球场白线自绘，往下滚镜头沿球场纵深推进 | 首屏就是产品本身 |
| 2 | 首屏标题 | 排版 | 中文**按字**揭开（`--i` 错峰 42ms） | 层级：让第一句话被读 |
| 3 | 首屏 | 氛围 | 鼠标跟随冷光（仅精确指针设备；触屏或减少动效时一句 JS 都不执行） | 球馆的灯跟着你走 |
| 4 | 滚动 | 图像变换 | 印相表格子逐格显影，错峰靠**推进度区间**而不是加时长 | 奖励往下滚 |
| 5 | 交互 | 状态过渡 | 场馆详情的棋盘按行逐格落位（换日期重新落一次）；格子弹簧按压反馈 | 理解：70 格一次糊上来读不动 |
| 6 | 收尾 | 排版 | 规格带数字滚动到位、收尾条错峰浮起 | 收束 |

必守：
- `prefers-reduced-motion: reduce` 时**不是关掉，是给一张排好的静帧**（镜头停在构图最好的一帧、线已画完、格子全部显影、标题字全部就位）。已实测：标题字 `opacity: 1`、规格数字 `transform: none`、棋盘 70 格全可见。
- 只动 `transform` / `opacity`；`grain` 永远静止。
- 页面**去掉全部动效也完整可读可用**（滚动时间线用 `@supports` 包着，不支持就是静态帧）。

## 8. 图片（第二轮改过）

`frontend/public/img/` 一共 **8 个文件，全部 1200×800（3:2）**：

- `court-01 … court-05.svg` —— **5 张场馆封面是球场图纸**（全场 / 半场 / 发球区 / 球网立面 / 底线转角），五个视图同族、等尺寸、零人物、零网络，跟蓝图主题同源。
- `venue-detail-court.jpg` / `venue-detail-net.jpg` / `auth-visual.jpg` —— 3 张**真照片**，从 Pexels（Ben Cheers 室内羽毛球系列，Pexels License，可免费商用）里裁出的**确认无人**区域：场地地面与场线、看台与木地板、看台与木地板（登录页复用）。

**为什么封面不是照片**：那组照片全是动作照，人物就在画面中央，前景地板也躲不开脚；Pexels 上找不到可用的空场馆片源（Unsplash 本站要鉴权，Wikimedia / Openverse 在本机不通）。硬裁只会得到带人的碎图，所以封面改用图纸，真照片只留在确认无人的位置。

**要换成实拍照片**：把文件丢进 `frontend/public/img/`，改 `src/utils/venueVisual.js` 里 `DISTRICTS` 的 `file` 即可，其它地方不用动。**照片一律 1200×800、3:2**；`alt` 只写画面内容，不写具体场馆名。
